# iPhone Font Installation

## Abstract

Reference for installing custom fonts on iPhone using a third-party font installer app.

## Key Points

- iPhone does not install downloaded font files directly from Files.
- A third-party app such as `iFonts` is typically required to import the font.
- Installation usually completes through a configuration profile in `Settings`.

## Details

1. Download the font package, usually as a `.zip` file.
2. Open the file in a font installer app such as `iFonts`.
3. Follow the app's installation flow to generate the font profile.
4. When prompted, open `Settings` and allow the profile download.
5. Complete the profile installation in `Settings` to make the font available system-wide where supported.
