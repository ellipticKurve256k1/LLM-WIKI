## Abstract

This is a collection of my studies on Bitcoin, both technical and economic.

## Descriptions

This directory is organized as a set of topic-focused notes rather than a linear tutorial. Each note is meant to stand alone as a reference while still linking into a broader Bitcoin study graph.

Scope of the notes:

- Bitcoin wallet fundamentals such as mnemonic phrases, seeds, and key derivation
- Script and output types such as Taproot and SegWit-era constructions
- Quantum risk analysis for Bitcoin cryptography and UTXO exposure models
- Economic and protocol-level questions that become relevant while studying Bitcoin in practice

This README is only an index. The main content lives in the individual notes.
